# Night Vision Recorder (NVREC)


The purpose of this project is to provide a low-cost, 3D printed solution
for recording quality action video through a PVS-14 Style Night Vision
device. Current market options are either expensive, bulky, or poor quality.
This repository serves as a development starting point for creating a cheaper
alternative to what is currently available on the market with better functionality. Below is the current status of the project in terms of hardware selection and software functionality.

## Hardware Targets
+ Microcontroller | ESP32-P4-WIFI6
+ Camera Module   | OV5647 (1920x1080 @ 30FPS)

## Software Functions
+ Video Encoding
    + MJPEG (Status: Done)
    + MP4 (Status: WIP)

+ Video Streaming
    + WiFi (Status: WIP)

+ Video Recording
    + SD Card MP4 (Status: WIP)

+ Video Quality
    + Focus Control (Status: WIP)
    + Gain/Dynamic Range Control (Status: WIP)

+ Image Capture
    + Single Press Capture (Status: WIP)
